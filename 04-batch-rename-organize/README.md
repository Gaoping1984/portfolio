# 文件批量重命名 + 归类

## 解决什么问题
下载文件夹/共享盘里一堆 `IMG_0012.jpg`、`报价单 最终版(2).xlsx`，找不到东西。脚本按类型分到文件夹，并统一命名为 `日期_序号_原名.后缀`。

## 用法
```bash
python make_sample.py                     # 生成 12 个虚构杂乱文件
python organize.py                        # 预览，不改动任何文件
python organize.py 输入目录 输出目录 --apply
```
安全设计：默认只预览；执行时是**复制**到输出目录，不删除、不修改原文件；同时生成 `重命名对照表.csv` 方便回溯。只用 Python 标准库。

## 前后对比
```

报价单 最终版(2).xlsx    -> 表格/20260108_001_报价单_最终版_2.xlsx

未知文件.xyz             -> 其他/20260316_001_未知文件.xyz
```
注：日期取文件修改时间。完整结果见 `output/`。
